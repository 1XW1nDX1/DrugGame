# 药剂研发 - 成分与工艺定义表

这份文档用于整理药剂研发系统后续要用到的基础材料与工艺定义。

当前目标不是一次写完整数值系统，而是先把基础结构搭起来，方便后续补充。

## 1. 基础成分

基础成分用于决定药剂的大方向。第一版先保留最基础的三类，对应当前最容易落地的基础伤病需求。

### 1.1 止血基底

- 适用方向：止血类药剂
- 简单说明：用于承载促凝、止血相关活性成分，适合作为创伤急救药剂的基础底材。

### 1.2 镇痛基底

- 适用方向：镇痛类药剂
- 简单说明：用于承载缓解疼痛和减轻创伤刺激的活性成分，适合作为镇痛类药剂的基础底材。

### 1.3 抗感染基底

- 适用方向：抗感染类药剂
- 简单说明：用于承载抑菌、抗感染相关活性成分，适合作为伤口处理和感染控制类药剂的基础底材。

## 2. 活性成分

活性成分用于决定药剂的主要效果方向，是影响药效、生效速度和副作用表现的核心部分。

### 2.1 速凝提取物

- 主要效果：提高止血效率，缩短急救反应时间。
- 主要代价：可能提高组织刺激性，增加副作用风险。

### 2.2 强效镇痛剂

- 主要效果：快速缓解剧痛，降低创伤疼痛带来的即时影响。
- 主要代价：可能掩盖真实伤情，并带来较强副作用。

### 2.3 抑菌复合物

- 主要效果：抑制感染扩散，适合用于感染控制类药剂。
- 主要代价：可能提高成本，或对药剂稳定性造成压力。

### 2.4 抗炎活性剂

- 主要效果：减轻炎症反应，帮助伤情稳定。
- 主要代价：效果较温和，在极端战况下可能不够强力。

### 2.5 刺激恢复剂

- 主要效果：短时间内提高恢复表现或维持行动能力。
- 主要代价：容易带来额外副作用或后续负担。

## 3. 稳定成分

稳定成分用于提高药剂的可用性和稳定性，不直接决定主要药效方向，但会影响药剂是否平稳、是否容易失效以及副作用是否容易失控。

### 3.1 常温稳定剂

- 稳定作用：提高药剂在普通环境下的稳定性，降低变质和失效风险。
- 主要代价：可能让配方更保守，削弱部分即时效果。

### 3.2 缓释介质

- 稳定作用：让药效释放更平稳，并延长持续时间。
- 主要代价：可能降低药剂起效速度。

### 3.3 纯化辅助剂

- 稳定作用：减少制备过程中残留的非目标成分带来的负面影响，提高药剂整体稳定性。
- 主要代价：可能提高制作要求，增加材料或工艺负担。

### 3.4 副作用缓冲剂

- 稳定作用：缓和部分副作用表现，让药剂反应更加平稳。
- 主要代价：可能削弱活性成分的直接效果。

## 4. 工艺

工艺用于决定药剂的制作方式。它不直接决定药剂属于哪一类，但会影响药效表现、稳定性、起效速度和整体可用性。

### 4.1 过滤

- 工艺效果：去除部分不稳定残留，使药剂更加干净。
- 优点：有助于提高药剂稳定性，减少不必要的负面影响。
- 缺点：制作时间更长，对药效提升有限。

### 4.2 浓缩

- 工艺效果：提高主要成分浓度，使药剂效果更集中。
- 优点：有助于提升药效强度。
- 缺点：可能增加副作用，并降低药剂稳定性。

### 4.3 蒸馏

- 工艺效果：进一步提升药剂纯净度，使整体表现更加稳定。
- 优点：有助于提高药剂质量和稳定性。
- 缺点：制作要求更高，过程更慢。

### 4.4 粗制急配

- 工艺效果：快速完成基础制备，缩短研发准备时间。
- 优点：适合紧急情况，能够尽快形成可用原型。
- 缺点：药剂稳定性较差，结果不确定性更高。
