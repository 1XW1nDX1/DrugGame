# 药品成品对接文档

## 1. 文档目的

这份文档定义"药品成品（`FinishedDrug`）"的数据结构和生成逻辑，用于：

1. **研发系统** 输出给 **制造系统**（负责量产和批次管理）
2. **研发系统** 输出给 **主系统**（负责回合推进和前线投放）

本文档是**接口约定**，不是实现方案。各系统只需对齐这个数据对象即可独立开发。

## 2. 数据流向

```
药剂研发系统                审批系统                  制造系统 / 主系统
    │                         │                         │
    │ DrugPrototype           │                         │
    ├────────────────────────►│                         │
    │                         │                         │
    │                         │ ApprovalResult          │
    │◄────────────────────────┤                         │
    │                         │                         │
    │ 生成 FinishedDrug       │                         │
    ├─────────────────────────┼────────────────────────►│
    │                         │                         │
```

`FinishedDrug` 是研发+审批的最终输出。制造系统拿到它之后开始排产，主系统拿到它之后安排前线投放。

## 3. FinishedDrug 数据结构

### 3.1 字段定义

```csharp
public class FinishedDrug
{
    // ── 身份标识 ──
    public string DrugId;        // 唯一 ID，如 "Drug_001"
    public string DrugName;      // 显示名，如 "标准止血剂"
    public string DrugFamily;    // 所属路线：Hemostasis / Analgesic / AntiInfection

    // ── 审批信息 ──
    public string ApprovalMode;  // "FullTest" / "SimplifiedTest" / "Emergency"
    public float TestCompletion; // 测试完成度 0~100
    public string RiskGrade;     // "低" / "中" / "高"

    // ── 最终药效参数 (0~100) ──
    public float Efficacy;       // 治疗效率
    public float OnsetSpeed;     // 生效速度
    public float Duration;       // 持续时间
    public float Stability;      // 稳定性
    public float SideEffect;     // 副作用强度

    // ── 生产相关 ──
    public float BaseCost;       // 基础量产成本
    public string[] RequiredMaterials; // 需要的原料 ID 列表，如 ["Herb_Common", "Mineral_Iron"]

    // ── 风险标记 ──
    public float HiddenRisk;     // 隐藏风险值 0~100（供主系统判定事故概率）
}
```

### 3.2 字段说明

| 字段 | 类型 | 说明 | 谁用 |
|---|---|---|---|
| `DrugId` | string | 全局唯一，格式 `"Drug_{序号}"` | 所有人 |
| `DrugName` | string | 玩家可见名称 | UI / 主系统 |
| `DrugFamily` | string | 英文路线名 | 主系统做分类统计 |
| `ApprovalMode` | string | 审批方式 | 主系统追踪责任 |
| `TestCompletion` | float | 0~100，越高事故率越低 | 主系统判定事故 |
| `RiskGrade` | string | 直观风险标签 | UI 显示 |
| `Efficacy` | float | 治疗效率 0~100 | 主系统计算前线治愈率 |
| `OnsetSpeed` | float | 生效速度 0~100 | 主系统计算急救成功率 |
| `Duration` | float | 持续时间 0~100 | 主系统计算持续效果 |
| `Stability` | float | 稳定性 0~100 | 制造系统算批次波动 |
| `SideEffect` | float | 副作用强度 0~100 | 主系统算后遗症概率 |
| `BaseCost` | float | 单剂成本 | 制造系统算生产消耗 |
| `RequiredMaterials` | string[] | 原料 ID 列表 | 制造系统检查库存 |
| `HiddenRisk` | float | 隐藏风险 0~100 | 主系统判定突发事故 |

## 4. 原料 ID 约定

MVP 阶段只有止血路线，用到以下原料 ID：

```
Herb_Common   — 普通草药（止血基底、速凝提取物的原料）
Solvent_Basic — 基础溶剂（温和稳定剂、缓冲剂的原料）
```

> 后续扩展路线时，只需在研发系统的成分表中新增 ID，并同步告知制造系统即可。

## 5. 生成规则（研发系统内部，制造系统无需关心）

### 5.1 参数来源

`FinishedDrug` 的参数直接来自 `DrugPrototype` + `ApprovalResult`，不做二次计算：

```
FinishedDrug.Efficacy    = Prototype.Efficacy（审批不改疗效）
FinishedDrug.OnsetSpeed  = Prototype.OnsetSpeed（审批不改速度）
FinishedDrug.Duration    = Prototype.Duration（审批不改持续）
FinishedDrug.Stability   = Prototype.Stability（审批不改稳定）
FinishedDrug.SideEffect  = ApprovalResult 修正后的副作用
FinishedDrug.BaseCost    = Prototype.MassProductionCost
FinishedDrug.HiddenRisk  = ApprovalResult 修正后的隐藏风险
FinishedDrug.TestCompletion = ApprovalResult.TestCompletion
FinishedDrug.RiskGrade   = ApprovalResult.RiskGrade
```

### 5.2 原料映射

研发系统的成分 ID → 成品原料 ID 的简化映射：

| 成分 ID | 消耗原料 ID |
|---|---|
| `HemostasisBase` | `Herb_Common` |
| `RapidClot` | `Herb_Common` |
| `MildStabilizer` | `Solvent_Basic` |
| `BufferAgent` | `Solvent_Basic` |

所有配方额外消耗 1 个 `Solvent_Basic`（溶剂基底）。

去重后就是 `RequiredMaterials` 数组。止血药剂的 RequiredMaterials 固定为 `["Herb_Common", "Solvent_Basic"]`。

### 5.3 DrugId 生成规则

```
"Drug_" + (自增序号，从 001 开始，全局唯一)
```

> MVP 阶段用静态计数器即可，不做持久化。

## 6. 示例

研发系统生成一个止血药并走简化测试后，输出的 `FinishedDrug` 长这样：

```json
{
  "DrugId": "Drug_001",
  "DrugName": "速效止血剂",
  "DrugFamily": "Hemostasis",
  "ApprovalMode": "SimplifiedTest",
  "TestCompletion": 50.0,
  "RiskGrade": "中",
  "Efficacy": 70.0,
  "OnsetSpeed": 60.0,
  "Duration": 50.0,
  "Stability": 55.0,
  "SideEffect": 30.0,
  "BaseCost": 45.0,
  "RequiredMaterials": ["Herb_Common", "Solvent_Basic"],
  "HiddenRisk": 25.0
}
```

制造系统拿到这个对象后：
1. 检查 `RequiredMaterials` 库存是否充足
2. 用 `BaseCost` 计算生产总消耗
3. 用 `Stability` 和 `TestCompletion` 决定批次质量波动
4. 用 `HiddenRisk` 判定是否触发生产事故

主系统拿到这个对象后：
1. 用 `Efficacy`、`OnsetSpeed`、`Duration` 计算前线治疗效果
2. 用 `SideEffect` 计算后遗症概率
3. 用 `HiddenRisk` 判定是否触发特殊灾难事件
4. 用 `RiskGrade` 和 `ApprovalMode` 记录决策链（用于战后清算叙事）
