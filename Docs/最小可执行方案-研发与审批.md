# 最小可执行方案 — 药剂研发系统 + 审批系统

## 1. 目标

让研发系统和审批系统在 Godot 里**能点、能算、能看结果**，跑通"选成分 → 生成原型 → 选择审批方式 → 得到成品"这条最简链路。

不做：知识库、版本迭代、前线反馈、生产对接、事件总线、政策系统。

## 3. 研发系统 — 极简范围

### 3.1 药剂路线

**只做 1 条：止血（Hemostasis）**。

| 路线 | 基础成分 ID | 说明 |
|---|---|---|
| 止血 | `HemostasisBase` | 降低失血死亡率 |

### 3.2 成分池（硬编码，共 6 个）

**基础成分（1 个）**：

| ID | 说明 |
|---|---|
| `HemostasisBase` | 止血基底 |

**活性成分（1 个）**：

| ID | 效果 | 代价 |
|---|---|---|
| `RapidClot` | 疗效 +30，速度 +20 | 副作用 +15 |

**稳定成分（2 个）**：

| ID | 效果 | 代价 |
|---|---|---|
| `MildStabilizer` | 副作用 -15，稳定 +20 | 速度 -5 |
| `BufferAgent` | 副作用 -10，稳定 +10 | 疗效 -5 |

**工艺（2 个）**：

| ID | 效果 | 代价 |
|---|---|---|
| `StandardFilter` | 稳定 +15，副作用 -5 | 成本 +10 |
| `RapidMix` | 速度 +15 | 稳定 -15，副作用 +10 |

### 3.3 配方规则

- 基础成分：固定为 `HemostasisBase`（只有 1 个选项，UI 上显示即可）
- 活性成分：固定为 `RapidClot`（只有 1 个选项，UI 上显示即可）
- 稳定成分：可选 0~1 个（3 个选项：无 / MildStabilizer / BufferAgent）
- 工艺：必选 1 个（2 个选项：StandardFilter / RapidMix）

> 玩家实际只需做 2 个选择：**稳定成分**和**工艺**。其余自动填好。

### 3.4 原型参数计算

原型输出 **6 个显性参数 + 1 个隐藏风险**：

```
Efficacy   = 40 + 活性.疗效 + 稳定.疗效修正            → clamp [0,100]
OnsetSpeed = 40 + 活性.速度 + 工艺.速度修正 + 稳定.速度修正  → clamp [0,100]
Duration   = 50                                      → 固定值
Stability  = 40 + 稳定.稳定修正 + 工艺.稳定修正           → clamp [0,100]
SideEffect = 20 + 活性.副作用 + 工艺.副作用修正 - 稳定.副作用减免  → clamp [0,100]
Cost       = 30 + 工艺.成本                           → clamp [0,100]

HiddenRisk = SideEffect × 0.4 + (100 - Stability) × 0.3   → clamp [0,100]
```

### 3.5 不做路线匹配

只有一条路线，不存在错配，删除此逻辑。

## 4. 审批系统 — 极简范围

### 4.1 三种审批方式

| 方式 | 测试完成度 | 耗时（回合） | 隐藏风险降低 |
|---|---|---|---|
| 完整测试 | 90% | 3 | 降低 85% |
| 简化测试 | 50% | 1 | 降低 40% |
| 紧急授权 | 10% | 0 | 不变 |

副作用不再单独修正，统一通过隐藏风险体现。

### 4.2 审批结果

审批**不会否决**药剂（MVP 简化），只返回一个 `ApprovalResult`：

```
ApprovalResult
  - IsApproved        : true（永远通过）
  - TestCompletion    : 测试完成度 %
  - FinalHiddenRisk   : 修正后的隐藏风险
  - RiskGrade         : "低"(0~33) / "中"(34~66) / "高"(67~100)
  - ApprovalNote      : 一句提示文本
```

### 4.3 审批后→成品

审批通过后，系统基于 `DrugPrototype + ApprovalResult` 生成 `FinishedDrug`（药品成品），交给制造系统和主系统。
